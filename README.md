# Minería de Procesos 

Este repositorio contiene el desarrollo de un trabajo académico enfocado en **Minería de Procesos**, donde se aplican técnicas de descubrimiento y análisis de procesos a partir de registros de eventos (event logs).

## 📌 Objetivo
Descubrir, analizar y evaluar un proceso real utilizando algoritmos de minería de procesos y técnicas de conformidad, con el fin de comprender su comportamiento y detectar posibles desviaciones.

## 🧠 Metodología
El proyecto sigue las siguientes etapas:

1. **Carga y exploración de datos**
2. **Preprocesamiento del event log**
3. **Descubrimiento de procesos**
   - Alpha Miner
   - Inductive Miner
4. **Visualización del proceso (BPMN)**
5. **Conformance Checking**
6. **Análisis de resultados y conclusiones**

## 🛠️ Tecnologías utilizadas
- Python  
- Jupyter Notebook  
- Pandas  
- PM4Py (Process Mining for Python)
